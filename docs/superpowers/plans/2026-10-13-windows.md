# Daily Red en Windows

**Goal:** compilar y jugar localmente en Windows desde D:.

**Architecture:** MSYS2 local para herramientas POSIX y GCC host; xPack ARM GCC 14.2.1-1.1 para `MODERN=1`. Node sirve la web existente y Chrome ejecuta mGBA.

**Spec:** pedido del usuario en este chat, ejecución ya autorizada.

## Restricciones

- Código, herramientas, descargas, cachés y temporales dentro del proyecto en D:.
- Conservar commit pret, parche y verificaciones SHA-256 de vendor.
- Sin WSL, Docker, VM, cambios globales, publicación ni borrado de la copia original.
